# smart_band_10 — расписание ОмГУ на Xiaomi Smart Band 10

Показывает расписание пар ОмГУ на браслете Xiaomi Smart Band 10.

**Браслет полностью автономен.** Расписание вшито в сам `.rpk`, и приложение не обращается
ни в сеть, ни к телефону, ни в хранилище — в собранном пакете нет ни одного `@system.*`,
кроме роутера. Так вышло не от хорошей жизни: у браслета **одна активная bluetooth-сессия**,
и держит её Mi Fitness ради сна и пульса, поэтому синхронизация через телефон означала бы
выбор между расписанием и здоровьем (см. `docs/DECISIONS.md`).

```
eservice.omsu.ru --> server/ --(cli bake)--> shared/baked.json --(npm run gen)--> band-app/
```

Обновление расписания — пересборка и переустановка пакета, раз в две-три недели.
Расписание живёт двухнедельным циклом, поэтому вшитого хватает надолго.

Путь через телефон (`astrobox-plugin/` и протокол в `band-app/src/common/link.js`)
**рабочий, но сейчас не используется**: приложение его не вызывает. Удалять не стали —
он пригодится, если синхронизация когда-нибудь снова понадобится.

## Каталоги

| Путь | Что это |
|---|---|
| `server/` | FastAPI-сервер: тянет API вуза, нормализует, отдаёт компактный JSON и ICS |
| `shared/` | Контракт и данные: `schema.json`, `example.json`, `bells.json`, `baked.json` (вшиваемое расписание) |
| `band-app/` | Vela quick app для браслета (`.rpk`), package `ru.omsu.bandschedule`. Автономен: расписание внутри пакета |
| `astrobox-plugin/` | Плагин AstroBox v2: Rust → WebAssembly (`wasm32-wasip2`), пакет `.abp`. Собирается в WSL — Smart App Control блокирует cargo.exe |
| `reference/` | **Только чтение.** Код старого проекта StudyHelper, источник проверенных решений |
| `docs/` | `VELA-RULES.md` — правила платформы браслета; `DECISIONS.md` — журнал решений и ограничений; `ORIGINAL_SPEC.md` — исходное ТЗ |

## Команды

```bash
# band-app
cd band-app && npm install && npm run gen
npm test          # 162 теста чистой логики, без эмулятора
npm run build     # dist/ru.omsu.bandschedule.debug.<версия>.rpk, с проверкой сборки
npx http-server preview -p 8123   # превью экранов в браузере
```

```bash
# server
cd server && uv sync
uv run ruff check . && uv run ruff format --check .
uv run pytest -q
uv run uvicorn app.main:app --reload --port 8080
uv run python -m app.cli check-names --group 5028   # проверить словарь сокращений
uv run python -m app.cli bake --group 5028 --subgroup 1   # расписание для работы без телефона

# деплой (OptiPlex)
docker compose up -d --build
```

## Правила

- **Перед любой правкой `band-app/` — прочитать `docs/VELA-RULES.md`.** Нарушение правил Vela
  не ловится ни тестами, ни компилятором: приложение молча показывает чёрный экран и может
  подвесить браслет целиком. Один раз это уже произошло.
- **Секреты только через env.** Токены, `.env`, ключи подписи не коммитим (см. `.gitignore`).
- **`reference/` не редактируем** — оттуда только копируем и адаптируем.
- Факт о платформе (Vela, AstroBox), не подтверждённый документацией или экспериментом,
  не используется в коде. Всё проверенное и все найденные ограничения — в `docs/DECISIONS.md`.
- `docs/ORIGINAL_SPEC.md` — исходное ТЗ, локальный файл вне репозитория; часть фактов в нём устарела
  (см. `docs/DECISIONS.md` → «Устаревшие источники»). При расхождении побеждает `DECISIONS.md`.
- Сервер запускается строго в один воркер: снапшоты, rate limiter и планировщик живут в памяти.
- В `band-app/src/common/*.js` **не должно быть ни одного `@system.*`** — это граница,
  которая позволяет тестировать всю логику на Node без эмулятора.
- `band-app/src/common/bells.js`, `mock.js` и `baked.js` генерируются (`npm run gen`),
  править вручную нельзя. `baked.js` — расписание, вшитое в сборку: браслет работает
  без телефона, потому что bluetooth-сессию у него обычно держит Mi Fitness.

## Ключевые факты

- Группа: `МБС-301-О-01`, `group_id=5028`. Подгруппа задаётся при сборке: `cli bake --subgroup N`.
- Расписание 7-го семестра — строгий двухнедельный цикл: среда, четверг и суббота одинаковы
  каждую неделю, чередуются только понедельник и вторник. Цикл воспроизводит все 20 учебных
  дней семестра без расхождений.
- Таймзона везде `Asia/Omsk`. «Сегодня» — только `datetime.now(ZoneInfo(tz)).date()`.
- API вуза отдаёт всю историю с 2023 года одним ответом на 1.5 МБ; вперёд публикует ~10 дней.
- Полезная нагрузка на браслет — около 4 КБ на 14 дней. На устройстве проверено, что
  сообщение в 4288 байт проходит одним кадром (актуально для неиспользуемого сейчас
  пути через телефон).
