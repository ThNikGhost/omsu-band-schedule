# План: первое приложение (Hello World) для Xiaomi Smart Band 10

## Context

Вы недавно купили Xiaomi Smart Band 10 (= Mi Band 10, Xiaomi переименовала
линейку с 10-го поколения) и хотите попробовать написать для него своё мини-
приложение. По итогам исследования (включая reddit-тред r/miband и официальную
документацию) подтверждено: для Smart Band 10 существует **официальный
фреймворк Xiaomi Vela Quick App**, который позволяет писать приложения на
JavaScript + декларативной разметке `.ux` и собирать их в пакет `.rpk`.
Mi Band 10 явно перечислен в списках поддержки сенсорных API. Установка `.rpk`
на устройство выполняется с Android-телефона через `Notify for Xiaomi` или
моддированный Mi Fitness.

Цель этого плана — пройти весь путь end-to-end **на минимальном Hello World**
(одно окно, надпись, кнопка, реакция на тап + вибро), чтобы:

1. Поднять и проверить тулчейн (Node.js, AIoT CLI, эмулятор).
2. Получить рабочую сборку `.rpk`.
3. Установить её на реальный браслет и убедиться, что весь конвейер работает.

После этого любую следующую идею (счётчик тренировок, скорборд, виджет HA)
можно будет делать поверх готового скелета.

---

## Целевой результат

- Папка-проект `helloband/` в `D:\vscode\smart_band_10\` с исходниками Vela
  Quick App.
- Файл сборки `helloband.rpk` (~единицы КБ).
- Приложение запускается в эмуляторе AIoT (капсульный экран 212×520).
- Приложение установлено на физический Smart Band 10 и реагирует на тап.

## Шаги

> Опыт JS у вас минимальный — поэтому ниже подробнее, чем обычно. Концептуально
> файл `.ux` устроен как однофайловый компонент Vue: шаблон + стили + скрипт
> в одном файле. Сравнение с Vue SFC намеренное — в основе Quick App лежит
> аналогичная идея.

### Шаг 1. Подготовить окружение

1. Установить Node.js LTS (≥18) с https://nodejs.org/. После установки в
   PowerShell `node -v` и `npm -v` должны печатать версии.
2. (Опционально, рекомендую) Скачать **AIoT-IDE** с
   https://iot.mi.com/vela/quickapp/en/tools/ide/ — это VS Code с готовым
   расширением для подсветки `.ux` и кнопками запуска эмулятора. Можно обойтись
   обычным VS Code + ручным `aiot` CLI, но IDE упростит первые шаги.

**Проверка:** `node -v` ≥ v18, `npm -v` ≥ 9.

### Шаг 2. Создать проект

В PowerShell, в `D:\vscode\smart_band_10\`:

```powershell
npm create aiot
```

CLI спросит шаблон (выбрать Quick App / стандартный) и имя проекта (`helloband`).
Будет создана структура примерно такая:

```
helloband/
├── manifest.json     # пакет, иконка, разрешения, целевые устройства
├── app.ux            # глобальный скрипт жизненного цикла
├── pages/
│   └── index/
│       └── index.ux  # главный экран (template + style + script)
├── i18n/             # локализации
└── package.json
```

**Критические файлы** (мы их трогаем):

- `manifest.json` — здесь указываются `package`, `name`, `versionName`,
  `icon`, минимальная версия Vela, **разрешения** (`feature` блок:
  `system.vibrator`, `system.router` и т.д.) и список окон (`router.pages`).
- `pages/index/index.ux` — единственный экран Hello World.

### Шаг 3. Собрать минимальный Hello World

Внутри `pages/index/index.ux` — три блока: `<template>` (вёрстка),
`<style>` (стили), `<script>` (логика). Логика Hello World:

- крупная надпись «Hello, Band!» по центру;
- кнопка «Tap me»;
- по тапу: меняется текст на «Tapped N» и срабатывает короткая вибрация
  через `system.vibrator`.

Это упражнение проверяет три вещи: рендер UI, обработка событий, обращение
к системному API.

В `manifest.json` нужно:

- В `features` добавить запись `{ "name": "system.vibrator" }`.
- В `config.minPlatformVersion` оставить значение по умолчанию из шаблона.
- В `router.entry` указать `pages/index`.

### Шаг 4. Прогнать в эмуляторе

```powershell
cd helloband
aiot start
```

При первом запуске CLI создаст AVD. Профиль экрана надо выбрать
**капсульный** (это и есть Smart Band 10 — 1.72", 212×520). Если `aiot start`
не предложит выбор сразу — создать руками: `aiot crateVelaAvd`
(имя метода такое — это не опечатка).

В эмуляторе должен открыться экран приложения, тап на кнопку — счётчик растёт.

**Проверка:** счётчик увеличивается, нет красных ошибок в консоли `aiot start`.

### Шаг 5. Собрать `.rpk`

```powershell
aiot build
```

В папке `dist/` появится `helloband.rpk`.

**Проверка:** размер файла ненулевой, `manifest.json` внутри `.rpk`
(это zip) содержит ваше имя пакета.

### Шаг 6. Установить на браслет

С Android-телефона:

1. Установить **Notify for Xiaomi** ≥ 22.0.0 из Google Play
   (https://mibandnotify.com/xiaomi-mi-band/).
2. В приложении подключиться к Smart Band 10 (если уже подключён в Mi Fitness
   — потребуется отвязать от Mi Fitness и привязать к Notify; либо
   использовать второй способ ниже).
3. Перебросить `helloband.rpk` на телефон (USB / облако / Telegram saved
   messages).
4. В Notify: `Update Firmware → Third-party App or Watchface` → выбрать
   `.rpk` → дождаться передачи по BLE.
5. На браслете в меню приложений должен появиться **HelloBand**. Запустить,
   проверить тап и вибро.

Альтернатива (если не хочется отвязываться от Mi Fitness): моддированный
Mi Fitness от m0tral / ReVanced — раздел `Device → Apps` принимает `.rpk`
напрямую. Инструкции и сборки: https://github.com/m0tral и
https://vanced.to/revanced-mi-fitness.

**Проверка:** приложение видно в карусели браслета, открывается, кнопка
работает, вибро срабатывает.

## Подводные камни (на что обратить внимание)

1. **iOS не поддерживается**. У вас Android — порядок, но если потом возьмёте
   iPhone, путь установки сломается.
2. **Wi-Fi на браслете нет.** Если позже захочется HTTP — `fetch` пойдёт
   через **мост к спаренному телефону** (Vela Interconnect). Для Hello World
   это неважно.
3. **Lua + lvgl, упомянутый в reddit-треде, к Band 10 не относится** — это
   движок циферблатов для Mi Band 8 Pro / 9 / 9 Pro / Watch S3-S5. Не путать.
4. **Привязка к одному клиенту.** Браслет одновременно дружит с одним
   приложением-компаньоном. Notify и Mi Fitness конкурируют за подключение —
   при переключении устройство просит сброс. Это нормально, не пугаться.
5. **Версия Vela на устройстве**. В `manifest.json` есть
   `config.minPlatformVersion`. Если поставить выше, чем установлено на
   браслете, `.rpk` не запустится. Оставлять значение из шаблона; при
   несовпадении — обновить прошивку браслета через Mi Fitness и проверить
   снова.

## План тестирования

End-to-end один прогон:

- [ ] `node -v` ≥ 18, `npm -v` ≥ 9 в PowerShell.
- [ ] `npm create aiot` создаёт проект без ошибок.
- [ ] `aiot start` запускает эмулятор; экран рисуется, кнопка реагирует.
- [ ] `aiot build` создаёт `dist/helloband.rpk` ненулевого размера.
- [ ] Notify for Xiaomi на Android-телефоне видит браслет и принимает `.rpk`.
- [ ] На браслете приложение появляется, открывается, тап увеличивает
      счётчик, вибро срабатывает.

После того как этот скелет работает, любая следующая идея (счётчик
тренировок, скорборд для падел-тенниса, виджет HomeAssistant) делается
поверх него — меняется только содержимое `index.ux` и, при необходимости,
блок `features` в `manifest.json`.
