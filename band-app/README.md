# band-app — приложение для Xiaomi Smart Band 10

Vela quick app, package `ru.omsu.bandschedule`, экран 212×520.

**Фаза 2: работает на вшитых демонстрационных данных.** Приёма расписания с телефона
пока нет — он появится в фазе 4 (`@system.interconnect`).

## Устройство

Вся логика лежит в `src/common/*.js` и **не импортирует ни одного `@system.*`**. Это
сделано намеренно: эмулятор Vela тяжёлый, на устройстве не отладишься, а так весь расчёт
состояний проверяется обычными тестами на Node. Компонент страницы только раскладывает готовые
строки по элементам.

| Файл | Ответственность |
|---|---|
| `common/clock.js` | что происходит сейчас: идёт пара, перемена, большой перерыв, пары кончились |
| `common/viewmodel.js` | готовые строки для каждого экрана |
| `common/schedule.js` | чтение кэша, поиск дня, «данные устарели» |
| `common/format.js` | время, даты, русские склонения. Без `Intl` — его на Vela может не быть |
| `common/bells.js`, `common/mock.js` | **генерируются** из `shared/` командой `npm run gen` |
| `pages/index/index.ux` | единственная страница: пять экранов, переключение по тапу |

Перемены считаются по **парам студента**, а не по сетке звонков: у человека с 1-й и 4-й парой
между ними не «перемена», а окно, и ему важно, когда начнётся 4-я.

## Превью без эмулятора

```bash
npx http-server preview -p 8123
```

Затем открыть `http://127.0.0.1:8123/` (или любым другим статическим сервером из корня
`band-app`, тогда `http://127.0.0.1:8123/preview/`).

Страница рисует все пять экранов в рамке 212×520, используя **те же модули** `src/common/*.js`
и те же размеры, что `index.ux`. Есть ползунок времени и кнопки состояний: идёт пара, перерыв
внутри пары, большой перерыв, после пар, день без пар. Экран, в который содержимое не влезло,
обводится красным.

Это **приближение**, а не эмулятор: шрифт и метрики строк на браслете свои. Итоговый вид
проверяется в эмуляторе AIoT-IDE.

## Что ещё не проверено на устройстве

Сборка `.rpk` проходит, и компилятор принимает всю вёрстку, но **рендер на реальном экране
не проверялся** — эмулятор Vela ставится отдельно вместе с AIoT-IDE. Проверить в первую очередь:

- **Название приложения.** Документация Vela ограничивает `name` шестью иероглифами;
  «Расписание» — десять символов и может обрезаться в списке приложений. Запасной вариант — «ОмГУ».
- **Символ `…`** в сокращённых названиях: если шрифт его не содержит, поменять `ellipsis`
  в `server/abbreviations.yaml` на `..` и перегенерировать данные.
- **Прокрутка `<list>`** на дне с шестью и более парами.
- **`designWidth: "device-width"`** — значение взято из рабочего приложения под Vela; в
  официальном шаблоне стоит число 480. Если масштаб окажется не 1:1, поменять на число.
- Читаемость кегля 12–15 px на 1.72″.
